# GSD Skill

Ensure methodical, step-by-step progress across all project phases.

## Execution Checklist
1. Review phase requirements and active constraints.
2. Outline specific file modifications and expected behavior.
3. Apply changes cleanly without introducing extraneous logic.
4. Execute tests or syntax checks to verify every change.
5. Summarize completed items and pause for verification at each phase gate.
