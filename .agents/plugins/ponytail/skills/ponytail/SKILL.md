# Ponytail Skill

Solve coding tasks with the absolute least new code while ensuring correctness, robustness, and accessibility.

## Guidelines
- Before implementing, check if the requirement can be satisfied by reusing existing functions, standard library methods, or HTML5 native attributes.
- Avoid introducing unnecessary wrapper functions, abstract base classes, or auxiliary libraries when straightforward native implementations exist.
- Review diffs to trim accidental bloat or unneeded abstractions.
